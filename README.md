**peltraCom** adalah platform *Company Profile* resmi untuk **PT Pelabuhan Lembar Sejahtera**. Website ini dirancang untuk memberikan informasi terkini, layanan pelabuhan, serta berita terbaru seputar perusahaan secara dinamis dan profesional.

---

## ✨ Fitur Utama

- **🌐 Landing Page Profesional:** Memperkenalkan profil perusahaan, visi, misi, dan layanan utama.
- **📰 News & Updates:** Sistem manajemen berita untuk menyajikan informasi terkini di sekitar perusahaan.
- **⚡ Filament Admin Panel:** Dashboard admin yang powerful untuk mengelola konten website dengan mudah tanpa menyentuh kode.
- **📱 Responsive Design:** Optimal diakses dari berbagai perangkat (desktop, tablet, maupun smartphone).
- **🚀 Built with Laravel 12:** Menggunakan standar terbaru framework Laravel untuk keamanan dan performa maksimal.

---

## 🛠️ Stack Teknologi

- **Framework:** [Laravel 12](https://laravel.com/)
- **Admin Panel:** [Filament PHP](https://filamentphp.com/) (TALL Stack: Tailwind, Alpine.js, Laravel, Livewire)
- **Database:** MySQL
- **Frontend:** Tailwind CSS & Blade Templating
